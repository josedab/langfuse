## Core Concepts

### Trace
A single execution flow in an LLM application. Represents one complete request-response cycle, containing multiple observations.

**Example:** A chatbot receiving a user message, calling an LLM, and returning a response.

**Key Fields:**
- `id`: Unique identifier
- `projectId`: Parent project
- `timestamp`: When trace started
- `input`/`output`: Request and response data
- `metadata`: Custom key-value pairs
- `tags`: Categorization labels

### Observation
A single event within a trace. Can be a span (timed operation), generation (LLM call), or event (point-in-time).

**Types:**
- **SPAN**: A timed operation (e.g., database query)
- **GENERATION**: An LLM call with input/output
- **EVENT**: A point-in-time occurrence

**Key Fields:**
- `trace_id`: Parent trace
- `parent_observation_id`: For nested observations
- `start_time`/`end_time`: Duration
- `level`: DEBUG, DEFAULT, WARNING, ERROR

### Score
An evaluation metric attached to a trace or observation. Can be numeric, categorical, or boolean.

**Sources:**
- **API**: Programmatically set via SDK
- **ANNOTATION**: Human-provided scores
- **EVAL**: Auto-generated by evaluation jobs

**Data Types:**
- `NUMERIC`: Floating-point value
- `CATEGORICAL`: String label
- `BOOLEAN`: True/false

## Architecture Terms

### tRPC Router
A type-safe API endpoint handler using the tRPC library. Provides automatic TypeScript types between client and server.

**Example:** `datasetRouter`, `traceRouter`, `evalRouter`

### Procedure
A single endpoint within a tRPC router. Can be a query (read) or mutation (write).

**Types in Langfuse:**
- `publicProcedure`: No authentication required
- `authenticatedProcedure`: Requires valid session
- `protectedProjectProcedure`: Requires project membership
- `protectedOrganizationProcedure`: Requires org membership

### Service Layer
Business logic separated from route handlers. Services are called by procedures and interact with databases.

**Pattern:**
```
tRPC Procedure → Service → Repository/Prisma
```

### Repository
Data access layer abstraction for complex queries, especially ClickHouse operations.

**Location:** `/packages/shared/src/server/repositories/`

## Database Terms

### Prisma
ORM (Object-Relational Mapping) for PostgreSQL. Generates TypeScript types from schema.

**Key Files:**
- `schema.prisma`: Database schema definition
- `prisma migrate`: Migration tool
- `prisma generate`: Type generation

### ClickHouse
Column-oriented OLAP database for analytics. Stores high-volume trace data.

**Table Engine:** ReplacingMergeTree
- Handles updates via versioning (`event_ts`)
- Soft deletes via `is_deleted` flag

### ReplacingMergeTree
ClickHouse table engine that deduplicates rows during merge operations based on a version column.

**Usage:** `SELECT ... FINAL` forces merge to get latest version.

### Lookback Window
Time buffer used in ClickHouse queries to find related entities across partitions.

**Examples:**
- Trace → Observation: +1 hour
- Observation → Trace: -2 days
- Score → Entity: ±1 hour

## Queue System Terms

### BullMQ
Redis-based job queue library. Handles background processing with retries and priorities.

**Components:**
- **Queue**: Job storage
- **Worker**: Job processor
- **Job**: Unit of work

### Queue Sharding
Distributing queue jobs across multiple Redis instances using consistent hashing.

**Key:** `${projectId}-${eventBodyId}`

### Dead Letter Queue (DLQ)
Storage for failed jobs after max retry attempts. Used for debugging and manual retry.

## Authentication & Authorization

### RBAC (Role-Based Access Control)
Permission system based on roles at organization and project levels.

**Levels:**
1. Organization roles (OWNER, ADMIN, MEMBER, VIEWER)
2. Project roles (OWNER, ADMIN, MEMBER, VIEWER)

### Scope
A specific permission within RBAC system.

**Examples:**
- `traces:read`: View traces
- `prompts:CUD`: Create/Update/Delete prompts
- `projectMembers:CUD`: Manage project members

### Entitlement
Plan-based feature access. Determines which features are available based on subscription tier.

**Plans:** Free, Pro, Team, Enterprise

### API Key
Authentication credential for public API access.

**Types:**
- **Public Key** (`pk-lf-*`): Can be shared, limited scope
- **Secret Key** (`sk-lf-*`): Private, full scope

### Basic Auth
HTTP authentication using public and secret keys.
```
Authorization: Basic base64(publicKey:secretKey)
```

### Bearer Auth
HTTP authentication using only public key (limited to scores API).
```
Authorization: Bearer publicKey
```

## Feature Terms

### Dataset
A collection of test cases for evaluating LLM applications. Contains items with inputs and expected outputs.

**Components:**
- **DatasetItem**: Single test case
- **DatasetRun**: Execution of dataset against application
- **DatasetRunItem**: Result of single item execution

### Prompt
A versioned template for LLM calls. Supports variable interpolation and nesting.

**Features:**
- Version tracking
- Labels (e.g., "production", "staging")
- Dependencies on other prompts
- Caching in Redis

### Evaluation (Eval)
Automated scoring of traces using LLM-based or programmatic evaluators.

**Components:**
- **EvalTemplate**: Evaluator definition
- **JobConfiguration**: When/how to run evals
- **JobExecution**: Single eval run

### Annotation Queue
Human review workflow for scoring traces manually.

**Components:**
- **AnnotationQueue**: Queue configuration
- **AnnotationQueueItem**: Item pending review
- **AnnotationQueueAssignment**: Reviewer assignments

### Automation
Trigger-based actions on events (e.g., webhook on trace creation).

**Components:**
- **Trigger**: Event condition
- **Action**: Response (webhook, Slack)
- **AutomationExecution**: Action record

## Ingestion Terms

### Event
A single update to a trace, observation, or score. Multiple events merge into final entity state.

**Flow:** API → S3 → Queue → Worker → ClickHouse

### Event Batch
Multiple events submitted in a single API call.

**Response:** HTTP 207 (Multi-Status) with per-event results.

### eventBodyId
Unique identifier for the entity being updated. Used for event grouping and deduplication.

### S3 Event Storage
Temporary storage of events before processing. Enables replay on worker failure.

**Path:** `bucket/projectId/entityType/eventBodyId/fileKey.json`

## Observability Terms

### OpenTelemetry (OTEL)
Open-source observability framework for tracing, metrics, and logs.

**Components in Langfuse:**
- Trace context propagation
- Automatic instrumentation
- OTLP export to Datadog

### Span
A timed operation in distributed tracing. Not to be confused with observation SPAN type.

### traceException
Function to record exceptions in OpenTelemetry span and Datadog.

**Usage:**
```typescript
try {
  await operation();
} catch (error) {
  traceException(error);
  throw error;
}
```

### instrumentAsync
Wrapper function to create OpenTelemetry span around async operations.

**Usage:**
```typescript
await instrumentAsync({ name: "operation" }, async (span) => {
  // Traced code
});
```

## Security Terms

### AES-256-GCM
Encryption algorithm used for sensitive data. Provides confidentiality and authenticity.

**Components:**
- 256-bit key
- 12-byte IV (random per encryption)
- 16-byte authentication tag

### Webhook Signature
HMAC-SHA256 signature for webhook payload verification.

**Format:** `t=<timestamp>,v1=<signature>`

### CAPTCHA (Turnstile)
Cloudflare's privacy-focused CAPTCHA for bot protection on auth forms.

---

## Deployment Terms

### Turbo
Monorepo build system. Handles caching, task ordering, and parallel execution.

**Commands:**
- `turbo build`: Build all packages
- `turbo prune`: Create minimal dependency tree

### Health Check
Endpoint for container orchestrators to verify service readiness.

**Endpoints:**
- `/api/public/health`: Comprehensive check
- `/api/public/ready`: SIGTERM detection

### Graceful Shutdown
Proper termination allowing in-flight requests to complete.

**Implementation:** SIGTERM detection + health check failure

---

## Cloud Storage Terms

### MinIO
S3-compatible object storage for local development and self-hosting.

### Presigned URL
Time-limited URL for direct S3 upload/download without API credentials.

### Server-Side Encryption (SSE)
S3 encryption at rest options: AES-256 or KMS.
